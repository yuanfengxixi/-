## 七、平台特定优化

### Midjourney 优化
```
--ar 16:9 --v 6 --style raw --s 250
--ar 9:16 --v 6 --style raw --s 250 (portrait)
--ar 3:2 --v 6 --style raw --s 250 (landscape)
```

### Stable Diffusion 优化
```
Steps: 30-50
CFG Scale: 7-9
Sampler: DPM++ 2M Karras
Resolution: 1024x1024 or higher
```

### DALL-E 3 优化
```
Use detailed descriptions
Specify "digital art" or "oil painting"
Include style references
Mention color schemes explicitly
```
